# OesteVaquero – Migración WP → MDX (Next.js)

## Dónde subir el XML de WordPress
- Carpeta: `data/wp_export/`
- Nombre sugerido: `oestevaquero-export.xml`

Coloca aquí el archivo exportado desde WordPress (WXR/XML). Si pesa mucho puedes dejarlo como `.zip`.

## Estructura inicial
- `data/wp_export/` → XML(s) de exportación
- `content/` → aquí se generarán los `.mdx`
- `scripts/` → scripts de conversión

## Próximos pasos
1) Sube el XML a `data/wp_export/`.
2) Dime el nombre exacto del archivo para iniciar la conversión a MDX.
